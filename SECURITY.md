# Security policy

Security support covers the latest stable release.

Use [GitHub private vulnerability reporting](https://github.com/Galaxerr/repository-hygiene-skill/security/advisories/new) to report a vulnerability. The repository owner will monitor this channel. Keep vulnerability details out of public issues, pull requests, and discussions.

When submitting a private report, include the affected version or revision, impact, and sanitized reproduction steps. Remove credentials, personal data, and private repository content from supporting evidence.
