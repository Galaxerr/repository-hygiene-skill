# Security policy

Security support covers the latest stable release.

The repository owner will monitor GitHub private vulnerability reporting. The submission link is pending confirmation that the private form is visible to a non-maintainer and that the owner's notifications are configured. Keep vulnerability details out of public issues, pull requests, and discussions.

When submitting a private report, include the affected version or revision, impact, and sanitized reproduction steps. Remove credentials, personal data, and private repository content from supporting evidence.
